Reusable input component that supports text, email, password (with toggle), and icons.

Props:
- label?: string
- placeholder?: string
- icon?: string
- type?: string (default 'text')
- disabled?: boolean
- model: any with [(model)] two-way binding
- variant?: 'outlined' | 'underline'
- placeholderUppercase?: boolean
- togglePassword?: boolean (default true, only applies when type='password')
